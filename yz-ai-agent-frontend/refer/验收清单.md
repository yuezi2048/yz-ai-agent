# 数据丢失风险修复 - 完整验收清单

## 📋 修复概述

本次修复解决了客户、员工、供应商列表在数据量超过1000条时的数据丢失风险，通过使用新的后端接口替代原有的分页查询接口（`pageSize: 1000`）。

## ✅ 修复内容

### 1. 客户列表优化
- **旧接口**：`listClientByPageUsingPost({ current: 1, pageSize: 1000 })`
- **新接口**：`getClientCompanyNamesUsingGet()` + `getUserNameByCompanyNameUsingPost({ companyName })`
- **修复文件**：
  - `src/hooks/invoice/useClientManage.ts`
  - `src/hooks/invoice/useInvoiceQueryManage.ts`
  - `src/hooks/finance/useBankTransactionManage.ts`
  - `src/hooks/finance/useAccountsReceivableManage.ts`
  - `src/modal/invoice/InvoiceEditModal.vue` ⭐（本次新增修复）

### 2. 供应商列表优化
- **旧接口**：`listSupplierUsingPost({ current: 1, pageSize: 1000 })`
- **新接口**：`getSupplierCompanyNamesUsingGet()` + `getSupplierNameByCompanyNameUsingPost({ companyName })`
- **修复文件**：
  - `src/hooks/finance/useInputInvoiceManage.ts`
  - `src/modal/finance/OutflowPaymentModal.vue`

### 3. 员工列表优化
- **旧接口**：`listEmployeeUsingPost({ current: 1, pageSize: 1000 })`
- **新接口**：`getAllEmployeeBasicInfoUsingGet({})` 或 `getAllEmployeeBasicInfoUsingGet({ companyName })`
- **修复文件**：
  - `src/hooks/finance/useInputInvoiceManage.ts`
  - `src/hooks/finance/useBankTransactionManage.ts`
  - `src/hooks/invoice/useInvoiceQueryManage.ts`
  - `src/modal/employee/EmployeePermissionEditModal.vue` ⭐（本次新增修复）
